# ifs.gs

Gourav Sharma's personal site. Plain HTML and CSS with no build step. The theme is taken from iasxifs.com's original design.

- `index.html`: the homepage
- `style.css`: all the styles; the colors are variables at the top
- `assets/`: images. Add the portrait as `assets/portrait.jpg`; there's a comment in `index.html` showing where.
- `404.html`, `CNAME` and `.nojekyll`: files GitHub Pages uses

Preview locally:

    python3 -m http.server 8000 --directory site

The design source is the Claude Design project "ifs.gs".
